Documentation

svelteRedisAdmin is configured with one config.json (path in SRA_CONFIG). Its keys follow phpRedisAdmin: Servers with name, host, port, auth, db, databases, filter, separator, plus login and cookieSecret for authentication. A commented config.sample.json is in the repository.

Single sign-on & KubernetesTrust an SSO proxy (oauth2-proxy…), check Kubernetes RBAC per server, and discover the Redis of review namespaces. Kubernetes manifestsThe app with discovery and RBAC, two example review environments, and a local walkthrough.

Authentication at a glance

auth.plugin Who logs people in
config (default) The login form, against the login list (roles admin, rw, ro, optional servers list). No list: everyone is admin, like phpRedisAdmin's default install.
http HTTP Basic, against the same login list.
header An SSO proxy, through identity headers trusted only from auth.trustedProxies. Required for Kubernetes RBAC and server discovery. See Single sign-on & Kubernetes.
